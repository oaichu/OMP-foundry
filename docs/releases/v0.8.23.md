# OMP Foundry v0.8.23

## Summary

This release is the P0 governance and npm distribution baseline for OMP Foundry. It fixes the Plan approval reset bug, closes known shell/LSP mutation paths, persists retry state, and prepares npm publishing through the GitHub Actions release workflow.

## Included

- Derive `FOUNDRY_VERSION` from `package.json`.
- Preserve a completed Plan3 cycle at `awaiting_lock` during normal resume.
- Make `/ok`, `/run`, `/go`, and `foundry_step` lock an awaiting Plan through the same approval path as `/approve plan`.
- Deduplicate Product/Plan approval logic in `src/approve.ts`.
- Restrict governed bash to constrained read-only Git inspection outside discovery.
- Restrict governed LSP actions to read-only operations outside discovery.
- Persist `ticket.attempts` across state save/load.
- Route initial trivial/low-risk implementation work to `smol-implementer`; retries escalate to `hard-implementer`.
- Refuse `/plan-revise`, `/verify`, and `/release-check` on projects without Foundry state.
- Read update availability from the npm registry and recommend `omp plugin install omp-foundry`.
- Add npm package file filtering and provenance-enabled release publishing.
- Add end-to-end coverage for `/ok` at `awaiting_lock` and shell-gate injection cases.

## Installation

```text
omp plugin install omp-foundry
```

Git fallback:

```text
omp plugin install github:oaichu/omp-foundry#v0.8.23
```

Restart OMP after updating the plugin.

## Security and scope notes

- Artifact protection uses content hashes and extension-owned state; it is not a signed cryptographic lock.
- Worker isolation and patch validation are not an operating-system sandbox.
- The default verification runner remains trusted-host unless an external sandbox is explicitly configured.
- The tokenized argv/AST shell parser and CI publish dependency gate remain planned follow-ups.
