# Design knowledge provenance

OMP Foundry's design skills are original, distilled control-plane guidance. The upstream projects below are not vendored and are not runtime dependencies.

Reviewed 2026-08-27:

- `nextlevelbuilder/ui-ux-pro-max-skill` (MIT): visual-language and multi-platform design-intelligence inspiration.
- `pbakaus/impeccable` (Apache-2.0): critique, accessibility, interaction, motion, and visual-QA inspiration.
- `ibelick/ui-skills` (MIT): durable design-contract and context-routing inspiration.

Reviewed 2026-08-29:

- `anthropics/skills` (Apache-2.0): Frontend Design art direction, subject-grounded intent, typography/layout/signature choices, and two-pass critique inspiration.
- `shadcn-ui/ui` (MIT): component composition, registry patterns, and semantic token conventions.
- `vercel-labs/agent-skills` (Apache-2.0): Web Interface Guidelines review formatting, interaction contracts, and live rule retrieval pattern.

Foundry policy: keep one owner per capability, preserve progressive/JIT loading, and import upstream ideas only through deliberate review. The shipped text is an original Foundry distillation, remote rules are not vendored, and current official docs must be fetched when freshness matters. Do not auto-sync external skill corpora into the package.
